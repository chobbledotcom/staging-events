# Client logo sources

The client logos in this folder are all 300×300 JPEGs — too small for crisp
display on retina screens or anywhere larger than a small thumbnail. The
following sources can be used to obtain higher-resolution / vector versions.
Replace each file with a higher-res PNG or SVG (keeping the same filename) and
the rest of the site will pick it up automatically.

> Note: I (Claude) attempted to fetch these directly during this session but
> network egress is blocked from the sandbox, so they have to be downloaded
> manually.

## Alzheimer's Society — `alzheimers-society-logo.jpg`

- Wikimedia Commons SVG (free, multiple resolutions up to 2560×1569):
  https://commons.wikimedia.org/wiki/File:Alzheimers_Society_Logo.svg
- Brandfetch: https://brandfetch.com/alzheimers.org.uk
- Brand assets page: https://www.alzheimers.org.uk/

## Prostate Cancer UK — `prostate-cancer-uk-logo.jpg`

- Official logo download (request form, includes vector files in
  black/white, blue, pink, orange):
  https://prostatecanceruk.org/about-us/contact-us/downloading-our-logo
- Brandfetch: https://brandfetch.com/prostatecanceruk.org
