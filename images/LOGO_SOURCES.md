# Client logo sources

The client logos in this folder were originally all 300×300 JPEGs — too small
for crisp display anywhere larger than a small thumbnail. They have now been
replaced with higher-resolution versions sourced directly from each charity's
official website.

## Alzheimer's Society — `alzheimers-society-logo.jpg`

- **Now**: 860×500 — current 2023 brand (forget-me-not flower)
- Source: https://www.alzheimers.org.uk/ (homepage `<img>` asset)

## Prostate Cancer UK — `prostate-cancer-uk-logo.jpg`

- **Now**: 2000×1125 — official "Supporting Prostate Cancer UK" partner logo
  (white-on-black per PCUK brand guidelines for supporting organisations).
  Staging Events provides production for March for Men, so this is the
  correct partner mark to use.
- Source: https://prostatecanceruk.org/about-us/contact-us/downloading-our-logo

## CoppaFeel! — `coppafeel-logo.png`

- **Now**: 1600×553 — generated from the official primary-logo SVG. The
  previous file was a WebP saved with a `.png` extension; this is now a real
  PNG.
- Source: https://coppafeel.org/wp-content/uploads/2022/08/primary-logo.svg

## Epilepsy Society — `epilepsy-society-logo.jpg`

- **Now**: 576×244 — official site theme logo
- Source: https://epilepsysociety.org.uk/

⚠️ **The client page is still titled "Epilepsy UK"** but this logo is from
Epilepsy Society. There is no UK charity called "Epilepsy UK" — the two main
ones are Epilepsy Society (epilepsysociety.org.uk) and Epilepsy Action
(epilepsy.org.uk). Worth deciding which one is actually the client and
renaming `clients/epilepsy-uk.md` accordingly.

## The Children's Hospital Charity (Sheffield) — `childrens-hospital-charity-logo.jpg`

- **Not upgraded.** The current 300×300 file is still in place.
- The official site (sheffieldchildrens.org) only exposes a 300×200 version
  in its header and a white-on-transparent variant via the events platform
  (events.tchc.org.uk). The full-colour bear-and-text mark used in the
  current file isn't directly downloadable from the site.
- To upgrade: contact the charity at fundraising@sheffieldchildrens.org for
  brand assets, or use their press contact.
